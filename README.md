## Структура репозитория
* `hello.py` — демонстрационный скрипт на языке Python.
* `apb_slave.sv` — модуль ведомого устройства (APB Slave) с конечным автоматом и адресным пространством регистров.
* `apb_master.sv` — модуль ведущего устройства (APB Master), содержащий задачи `apb_write` и `apb_read`.
* `TB.sv` — модуль верхнего уровня (Testbench), объединяющий Master и Slave и подающий тестовые воздействия.
* `run.do` — TCL-скрипт для автоматической компиляции, запуска симуляции и построения временных диаграмм в САПР ModelSim.
* `README.md` — документация проекта.

## Карта регистров APB Slave (базовый адрес `0x7000_0000`)
* **`0x00`** — запись номера в списке группы (`14` / `0x0000_000E`). При записи значения с младшим битом `0` внутренний регистр `register_with_some_name` сохраняет константу `0xAAAA_AAAA`, при записи `1` в младший бит — `0x5555_5555`.
* **`0x04`** — запись даты в формате `дд.мм.гггг` (`11.11.2026` -> `0x1111_2026`).
* **`0x08`** — запись первых 4 букв фамилии в кодировке ASCII (`"KHAL"` -> `0x4B48_414C`).
* **`0x0C`** — запись первых 4 букв имени в кодировке ASCII (`"ANNU"` -> `0x414E_4E55`).
